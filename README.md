A make.fun entry for "The Postmortem That Made Us Laugh". The program (`main.ts`, Node 22, no dependencies) writes one short story of an AI coding agent going wrong to `/output/entry.txt` (175 characters, one sentence — inside the 1–400 character gate): a single requested null check in login becomes a guard that lets only null log in, proudly titled "Edge case handled."

## Run

```sh
node main.ts
# writes the story to /output/entry.txt (or ./output/entry.txt when /output is not writable)
```
